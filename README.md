# 🎯 JEE InsightX – Interactive JEE Main Analytics Dashboard

## 📌 Project Overview

JEE InsightX is an interactive data analytics dashboard developed using Microsoft Power BI to explore and analyze JEE Main examination-related information. The project provides insights into aspirant statistics, subject-wise weightage, year-wise question trends, chapter frequency, candidate category distribution, marks-to-percentile relationships, and college cutoff information.

The dashboard brings multiple analytical views together in one place, helping students explore examination patterns and understand important performance indicators through interactive visualizations and filters.

## 🎯 Project Objectives

- Analyze important JEE Main examination indicators.
- Understand subject-wise question weightage.
- Explore year-wise trends in difficulty levels and previous-year questions (PYQs).
- Identify frequently asked chapters across different years.
- Analyze candidate distribution across categories.
- Explore the relationship between marks and percentile.
- Review college and branch cutoff information.
- Provide interactive filtering for better data exploration.

## 📊 Key Performance Indicators (KPIs)

The dashboard includes six major KPI cards:

1. **Total Aspirants** – Displays the total number of aspirants.
2. **Highest Score** – Highlights the highest recorded score.
3. **Total Colleges** – Displays the number of colleges represented.
4. **Average Percentile** – Summarizes average percentile.
5. **Average Difficulty** – Represents the average difficulty measure.
6. **Total PYQs** – Displays the total number of previous-year questions.

## 📈 Dashboard Visualizations

- **Subject Weightage:** Compares subject-wise question weightage.
- **Year Trend:** Analyzes year-wise difficulty and PYQ trends.
- **Chapter Frequency Heatmap:** Explores chapter-wise PYQ frequency across different years.
- **Marks vs Percentile:** Visualizes the relationship between marks and percentile.
- **Candidates by Category:** Represents candidate distribution across categories.
- **College Cutoffs:** Displays college-wise and branch-wise cutoff information.

## 🎛️ Interactive Filters

The dashboard provides four slicers:

- Year
- Category
- Gender
- Subject

These filters allow users to explore specific subsets of the available examination data.
